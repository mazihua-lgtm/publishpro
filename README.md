# PublishPro

将一份内容适配为公众号、小红书与 Twitter/X 格式。

## 能做什么 / What it does
- 输出公众号标题、正文与互动引导
- 生成小红书短文案和话题标签
- 将长文切分为 280 字 Twitter/X 线程

## 快速使用 / Quick Start
```bash
python3 publishpro.py "标题" "正文" 职场
```

## 示例输出 / Example Output
```text
✅ wechat / xiaohongshu / twitter
```

## 技术栈 / Tech
- Python 3.9+；封面流程可配合 Pillow

## 适用场景 / Use Cases
- 多平台分发、内容格式复用
